# Guarded Trader v0.1.0: the platform, the drills and the negative results

> **Not financial advice.** This release has **no proven trading edge**. Every strategy it
> contains loses money at real fees. Don't trade real money because of it.

This is the first public release of Guarded Trader: a framework for running a small crypto
trading system in which an LLM may research strategies but can never place an order. It
publishes the system as built and drilled in September–October 2026, with live trading
paused.

## What you get

- **Freqtrade as the only thing that trades**, in dry-run by default, on 4h/1d bars.
- **Conductor**, a separate safety service with:
  - a USD ledger with profit fencing and CAD export;
  - halts for daily loss, drawdown, loss streaks, capital and correlation, each cleared only
    by a human;
  - a kill switch and a nuclear flatten from Telegram, with a typed confirmation code;
  - a fail-closed boot, and account isolation;
  - heartbeat, nightly backups and a read-only dashboard.
- **A research harness** that can't reach the network: walk-forward, a random-entry null,
  Deflated Sharpe, and a registry that counts every trial, failed ones included.
- **23 decision records, runbooks and drill records**, including how to rebuild the server
  from nothing and restore its ledger.

## What we found

| Result | Where |
|---|---|
| 4 registered strategies, 2022–2026, at the fee a small Kraken account pays: **all lose money**, none beats its random-entry null, BTC buy-and-hold beats all of them | [`docs/research/05-first-candidates.md`](../research/05-first-candidates.md) |
| At a 0.20 % fee one candidate beats its null, but still **fails Gate 1**, and loses again at twice that fee | [`docs/research/06-ndax-feasibility.md`](../research/06-ndax-feasibility.md) |
| All **6 safety drills passed** on the real server: kill switch, nuclear flatten, restart under a halt, heartbeat silence, backup restore, full rebuild | [`docs/drills/results-2026-10-04.md`](../drills/results-2026-10-04.md) |
| A venue was **rejected** because its API key's withdraw scope couldn't be verified | [ADR-0022](../05-adr/0022-ndax-rejected-for-live.md) |

No real money has been traded. The gates were never lowered to let a strategy through.

## Try it

Dry-run only, on your machine, with no exchange key:

```bash
git clone https://github.com/aplicy-com/guarded-trader.git && cd guarded-trader
cp .env.example .env   # fill in only the three FREQTRADE__API_SERVER__* values
make up && make logs   # expect "Dry run is enabled"; dashboard at http://127.0.0.1:8000
```

## Known limitations

- **No strategy passes Gate 1.** The included strategies are reference and research material.
- **Live trading is paused.** The $20 live-pilot package (ADR-0019) is built but has never
  run. Status and the conditions for resuming: [`docs/07-roadmap.md`](../07-roadmap.md).
- **Built for one operator**: one Kraken account, USD quote currency, CAD tax records, a
  one-time $100 principal. Other setups need changes and, for anything near the trading
  path, a new ADR.
- **The automated research loop is not built yet.** Conductor's LLM backend is a stub
  (`adapters/llm.py`, work package 3B). The candidates so far were written in AI-assisted
  sessions and run through the harness by hand. No agent runs unattended.
