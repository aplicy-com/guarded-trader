## Findings and follow-ups raised by this run

All fixed on branch `fix/drill-findings`:

1. **Silent `tailscale up` failure (D6).** cloud-init now logs a boxed `CLOUD-INIT ERROR` message; the Makefile and Terraform require the key to start with `tskey-auth-`; `provision-vps.md` and `rebuild-vps.md` warn about key ID vs key.
2. **Restore file permissions (D6).** `rebuild-vps.md` step 7 now `chmod 0644`s the restored files before `docker cp`-ing them in and chains the commands with `&&`, so `rm` never runs after a failure.
3. **Public SSH during bootstrap (D6).** `rebuild-vps.md` says public SSH may refuse while first boot runs, to check Tailscale/cloud-init first, and has a "Hetzner rescue mode" troubleshooting entry.
4. **Nuclear result sent twice (D2).** Telegram `/flatten` (and a failed `/kill`) now send the result once, as the command reply.
5. **`halts=0` for an unreadable ledger.** `drill-check.sh` prints `halts=unknown` (its stopped-conductor ledger peek also referenced an undefined `HALTS_PY`; now defined).
6. **`/resume` of a cleared halt.** Replies immediately that it is already cleared and lists active halts, no confirmation code.
